Exercice C1: Installer et configurer son environnement de travail en fonction du projet web ou web mobile

------------------------------------------------------

VS Code :  éditeur de code / code editor

------------------------------------------------------

CSS : Mise en page de l’HTML / HTML layout

------------------------------------------------------

JavaScript : pour rendre la page web dynamique et interactive / to make the web page dynamic and interactive.

------------------------------------------------------

Python : pour développer le serveur et l’API / for developing the server and API

------------------------------------------------------

MySQL / Workbench : pour gérer la base de données / for managing the database

------------------------------------------------------

MAMP : l’environnement serveur et base de données / the server and database environment 

------------------------------------------------------

Postman : pour tester les requêtes de l’API / for testing API requests.

------------------------------------------------------

Git : pour gérer les versions du projet / for managing project versions.
git add : prepare les modifcations 
git commit -m "commentaire" : enregistre les modifications avec un commentaire 
git push : envoie les modifications sur Github
git merge : fusionne 2 branches
git pull : recupere les derniers modifcation du depot
git status : affiche l'etat actuel des fichiers

------------------------------------------------------

W3C HTML Validator : vérification de la conformité du HTML 
W3C CSS Validator : vérification de la conformité du CSS 

------------------------------------------------------

OWASP --> sécurité des applications web et des API

GitHub changelog --> nouveautés de GitHub
réseaux sociaux et communautés de développeurs : découverte de nouveaux outils, extensions et bonnes pratiques
