Exercice C6 Développer des composants d'accès aux données SQL et NoSQL

------------------------------------------------------

Développement des composants CRUD:

-Create: création de données
-Read: Consultation de données
-Update: modifications de données
-Delete: suppression de données

------------------------------------------------------

Les composants Python permettent de gérer les différentes tables :

-chambre.py: gestion des chambres
-hotel.py : gestion des hôtels
-reservation.py : gestion des réservations
-utilisateur.py: gestion des droits et des rôles
-securite.py : gestion des données

------------------------------------------------------

Intégrité et confidentialité:
Exemples:
-verifier les relations entre hôtels, chambres, utilisateurs et reservations
-controler les dates d'arrivée et de départ 
-verifier le nombre de voyageurs 
-Hacher les mots de passe
-Limiter les droits d'accès a la base de données

------------------------------------------------------

Validation des entrées et sécurité SQL :

-Vérifier les adresses e-mail
-vérifier les dates
-contrôler le nombre de voyageurs
-vérifier les identifiants (chambres, hôtels, etc.)

------------------------------------------------------

Exemples de Test Unitaires:

-Tester l'ajout, la consultation, la modification et la suppression des hôtels.
-Tester la gestion des chambres.
-Tester la création et la modification des utilisateurs.
-Tester les données incorrectes.

------------------------------------------------------


Outils utilisés:

-Postman
-MySQL pour la vérification des données

------------------------------------------------------

Résolution des problemes rencontrés:

-Identifier le problème
-Reproduire l'erreur
-Analyser les messages d'erreur
-Localiser le problème
-Corriger le code
-Relancer les tests
